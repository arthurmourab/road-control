# RoadControl - Documento de suporte à agentes de IA

## Objetivo
Este documento tem como objetivo servir de referência de contexto e de padrão arquitetural para o sistema RoadControl (RC). Agentes de IA que lenham ou alterem o código de qualquer maneira devem consultar este documento antes de tomar sua decisões.

## O que o sistema é
RoadControl é um software em desenvolvimento que tem como objetivo auxiliar organizações no controle de suas frotas de automóveis, mas especificamente no controle de do abastecimento desses automóveis. O sistema pretende atuar como uma ponte entre as organizações e postos de combustível parceiros. O motorista de um veículo de uma organização que utilize o RC sempre deverá abastecer em um posto parceiro e registrar no app os dados desse abastecimento para controle da organização.
